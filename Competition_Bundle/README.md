# Competition Bundle

The Codabench bundle of the challenge.

| Path | Content |
| --- | --- |
| `competition.yaml` | Challenge configuration (phases and tasks) |
| `ingestion_program/` | Trains the submitted model and writes its predictions |
| `scoring_program/` | Compares the predictions with the test labels |
| `input_data/`, `reference_data/` | Training data and test labels (not included) |
| `sample_code_submission/` | Example submissions |
| `sample_result_submission/` | Predictions written by the ingestion program |
| `pages/` | Pages shown on Codabench: overview, data, evaluation, starting kit, terms |
| `utilities/` | Script that zips the bundle for upload |
